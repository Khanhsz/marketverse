# Architecture and Game Design Decisions

- 2026-10-19: MarketVerse defined as map-first rather than dashboard-first.
- 2026-10-19: Country Strategy Map: one country before international expansion; wide draggable map, no fog.
- 2026-10-20: Weekly turn-based system: 1 week/turn, 52/year, 104-week Campaign target; quarterly analytics only.
- 2026-10-20: React/TypeScript/PixiJS engine/UI separation.
- 2026-10-20: Alpha focuses on consumer electronics/home appliances in one country with 8 cities and 4 AI competitors.
- 2026-10-20: User prefers ChatGPT/Codex connected login rather than separate OpenAI API billing.
- 2026-10-20: Sprint status persists in GitHub, not chat memory; CI does not imply autonomous AI coding.
- 2026-10-20: Respect independent product IP and use only general business simulation principles from research.
