# Sprint 16: Alpha Integration & Release Candidate

## Goal
Deliver a verifiable playable Alpha, not a mockup.

## Implementation scope
End-to-end user journeys, replay and save migrations, scripted 104-week campaign, browser/device smoke, known-issues and release candidate checklist.

## Acceptance criteria
Build and tests pass, no severity-1 blockers, playable 104-week run, versioned Alpha candidate artifact; human gameplay review required before public release.

## Required outputs
- A traceable commit/PR with source changes and no unrelated refactors.
- Deterministic behavioral tests for any new simulation rules; browser smoke for changed UI.
- A passing `npm run verify` and any sprint-specific commands.
- An updated `docs/SPRINT_TRACKER.md`, `docs/AUTOPILOT_STATE.json`, and `CHANGELOG.md` with evidence.

## Constraints
Read `AGENTS.md`, `docs/GAME_DESIGN.md`, `docs/ARCHITECTURE.md` and `docs/QUALITY_GATES.md`. Do not skip acceptance gates to meet a timebox. No API key, paid runner or autonomous coding is activated by adding files.
