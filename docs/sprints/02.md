# Sprint 02: Country Strategy Map

## Goal
Replace static centered Pixi world with a camera-controlled large interactive map.

## Implementation scope
Add pointer drag pan; mouse wheel/trackpad zoom anchored at cursor; zoom bounds/reset; large vector country; multiple map layers (Market, Competition, Operations, Logistics, Economy) with labels; selection never fires on drag; retain camera on selection/window resize.

## Acceptance criteria
Pan/zoom smoothly on laptop, city interaction works with zoomed world, no fog or fuzzy raster, layer switch and camera reset work, browser smoke passes.

## Required outputs
- A traceable commit/PR with source changes and no unrelated refactors.
- Deterministic behavioral tests for any new simulation rules; browser smoke for changed UI.
- A passing `npm run verify` and any sprint-specific commands.
- An updated `docs/SPRINT_TRACKER.md`, `docs/AUTOPILOT_STATE.json`, and `CHANGELOG.md` with evidence.

## Constraints
Read `AGENTS.md`, `docs/GAME_DESIGN.md`, `docs/ARCHITECTURE.md` and `docs/QUALITY_GATES.md`. Do not skip acceptance gates to meet a timebox. No API key, paid runner or autonomous coding is activated by adding files.
