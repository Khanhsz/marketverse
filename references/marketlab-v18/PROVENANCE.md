# Provenance, usage permissions and validation boundaries

- Project: independent MarketLab V12–V18 prototype material, curated for MarketVerse.
- Marketplace Business Simulations is a third-party commercial product. These files are **not its code or proprietary data** and should not be branded as an official integration.
- Sources: simulation hypotheses and code authored in the prior MarketLab iterations. Public product descriptions can motivate *categories* of mechanics, not precise weights/formulas.
- No verified equivalence to the vendor's economic/AI/scorecard formulas. Segments and product categories may follow publicly named concepts, but numeric coefficients are synthetic.
- The V18 archive included many Python modules and tests. This repository intentionally stores **selected text references**; it does **not** contain the original entire runnable archive. The Python prototypes have imports/dependencies not all provided here.
- Historical V18 report records 401 passing tests, but that is **not** verification of MarketVerse current code.
- Do not copy unknown third-party graphics, brand assets, exact UI or protected text into MarketVerse. Build an original game system and design.
- Future empirical calibration: use only game outputs captured from permitted play; preserve input decisions, edition/version, conditions, rounds and output measures; separate train/test across *whole sessions*. Report uncertainty and out-of-sample error.
- Documentation ingestion does not change MarketVerse Sprint 01 acceptance or the authorization to implement economic effects.
