# MarketVerse — Sprint 01 Foundation
A map-first, weekly turn-based business simulation prototype.

## Repository
Private GitHub repository for MarketVerse. The source was committed via ChatGPT's connected GitHub integration.

## Development
Requires Node 22. Run `npm install`, `npm run verify`, and `npm run dev` locally.

## Features
React + TypeScript + Vite + PixiJS map preview, fictional country with three selectable cities and three companies, a deterministic 52-week calendar, serializable game state, seeded random generator, invariant checks, save/load to localStorage, and no-fog modern map UI.

## Constraints
Sprint 01 economic results are placeholders with **zero revenue impact**. Product decisions, real sales, logistics, cash flow, competitor intelligence and macroeconomic events belong to later sprints. Full browser smoke testing is pending; GitHub Actions runs verification when pushed.
